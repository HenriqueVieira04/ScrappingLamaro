# ScrappingLamaro

## Projeto Final – Programação Orientada a Objetos

Este projeto tem como objetivo automatizar a coleta de dados dos cursos de graduação da Universidade de São Paulo (USP), utilizando a biblioteca Selenium WebDriver para navegação automatizada e BeautifulSoup para extração de dados em HTML.

O programa acessa o sistema JúpiterWeb da USP, percorre as unidades e cursos disponíveis, coleta informações da grade curricular de cada curso e organiza os dados em estruturas orientadas a objetos. Com isso, é possível realizar consultas como listagem de cursos por unidade, detalhes de disciplinas, e identificação de disciplinas compartilhadas entre cursos.

O projeto foi desenvolvido como trabalho final da disciplina de Programação Orientada a Objetos.

## Estrutura de execução
Para rodar o código:
python main.py (n° de unidades a serem processadas)
